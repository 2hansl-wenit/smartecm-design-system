# SmartECM 문서 디자인 핵심 가이드 (공개 배포)
디자인 소스: https://github.com/2hansl-wenit/smartecm-design-system
기준: `SKILL.md`, `references/document-style.md`, `references/document-components.md`, `tokens/document-tokens.json`.

## 문서 제작
- A4 기본. 인쇄 여백 위 20mm / 좌우 21mm / 아래 19mm. 기본 푸터/페이지번호 없음. 제목·도입부는 문서 시작에만 한 번.
- 타이포: Pretendard Variable 우선, 본문 10pt/행간 1.72, 주요 섹션 번호/제목 18pt, 하위 항목 제목 13.5pt. 문장과 번호의 영역을 분리하고 제목 다음 문단이 떨어져 인쇄되지 않도록 처리.
- 색상: SmartECM 기본 #5C6BC0, SmartGCM #53B3A3. 사용자 선택 색상은 해당 문서에만 적용. 화이트 중심, 절제된 포인트 색, 높은 대비, 과도한 카드/배지 금지.
- 표: 텍스트 길이·정보 중요도에 따라 열 너비를 조절. 기능명 등 긴 내용을 담는 열에 공간을 더 주고, 헤더/행 비율 일치. 경계선은 얇고 차분하게. 행 및 섹션의 페이지 중간 잘림 방지.
- 다이어그램: 박스와 실선 연결, 인쇄에서도 선·노드가 사라지지 않도록 보더 이용. 문서 외적인 샘플 수치를 사실로 주장하지 않음.
- 표지 01: 우측 상단 로고, 중앙 제목/부제목, 하단 작성자·작성일. 표지 02: 편집형, 좌상단 로고, 한 줄 제목·부제목, 짧은 포인트 바.
- **출력 기본**: 파일 형식 미지정 시 완성된 독립형 HTML 1개. 화면 상단 고정 'PDF로 인쇄' 버튼 → `window.print()`. `@media print`에서 툴바 숨기고 A4 본문만 인쇄. 명시된 PDF/DOCX 요청이 우선.
- 웹폰트: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css` 를 HTML `<head>`에 stylesheet로 포함. 오프라인은 폴백 또는 승인된 자체 호스팅 필요.
- 사용자 자료를 사실 근거로 사용. 자료가 없거나 불충분하면 결과를 샘플/미확인으로 구분하고, 고객사·계약·지원 성능·가격·증적을 임의로 확정하지 않음.
