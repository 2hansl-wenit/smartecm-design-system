# 문서 컴포넌트 계약

## 구조와 사용

- `scripts/document-library.js`: 메뉴, 공통 렌더러, 비식별 샘플 데이터 및 템플릿 조합.
- `styles/document.css`: 기존 제목·본문·표·KPI·일정의 시각 규칙.
- `styles/doc-layout.css`: 기존 인쇄·인용·검증 질문 규칙.
- `styles/document-library.css`: 가로형·독립 표지·새 컴포넌트·라이브러리 배치.
- `documents.html`: 위 파일을 로드하는 독립 문서 미리보기. Studio는 같은 페이지를 임베드하고 메뉴 정의도 공유한다.

공통 마크업은 `SmartECMDocuments.components`에서 한 번만 정의한다. 템플릿은 데이터와 조합 순서만 달리한다. HTML 문자열을 데이터에 넣지 않는다. 텍스트는 렌더러에서 이스케이프된다. 이미지 경로는 신뢰할 수 있는 프로젝트 자산만 사용한다.

```js
const {block, render} = SmartECMDocuments;
const summary = block("facts", {
  rows: [["문서 상태", "검토용"], ["작성일", "확정된 날짜 입력"]]
});
container.innerHTML = render(summary);
```

**일정**은 별도 HTML을 만들지 않고 `table`에 단계·기간·작업·산출물 데이터를 전달한다.
라이브러리는 **25개 샘플 예시, 22개 공유 렌더러**를 제공한다. 초기 15개와 새로운 다단/요약/체크/비교형 예시를 유지하면서 스펙 리스트를 제거하고 추천안 강조 표를 추가했다.

## 추천안 강조 표와 인쇄

- ‘일반 표’ 바로 다음에 독립된 ‘추천안 강조 표’ 예시를 배치한다. 추천 열의 머리글에 **★ 추천** 표시와 액센트 글자색을 적용하고, 헤더부터 마지막 행까지 굵은 테두리로 감싼다.
- `recommendedTable`은 3열의 `headers`와 `rows`, `recommendedColumn`(1 또는 2)을 받는다. 첫 번째 열은 평가 기준 30%, 각 대안은 35%로 구성한다. 이 구조를 변경하려면 오버레이의 시작 위치도 변경해야 한다.
- 선택된 열은 포인트 컬러 `var(--accent)`의 테두리, 매우 옅은 배경, 별 표시로 표현한다. 강조 표는 *디자인 사용 예시*이므로 실제 대안 A가 더 적합하다는 주장으로 읽히지 않게 캡션에 샘플임을 명시한다.
- `@media print`에서 표를 되도록 한 페이지에 배치하고, 선택 열 전체의 오버레이 테두리와 제목을 보존한다. 모바일에서도 표의 동일한 열 구성을 유지한다.

## 연결형 아키텍처 및 일정2

- 기존 3단 텍스트 목록 대신 `doc-architecture-diagram`의 독립된 노드 박스·연결선·화살표를 사용한다. 연결선은 CSS `border` 기반으로 작성하여 PDF 인쇄에서 사라지지 않게 한다.
- 모바일은 노드를 세로로 배열하고 연결선을 아래 방향으로 전환한다. A4 인쇄는 가로형 3단 도식을 유지한다.
- 일정2의 기간 바는 `background:var(--accent)`, `color:#fff`, `font-weight:700`로 강화한다. PDF 인쇄에서는 `print-color-adjust:exact`로 색상 보존을 요청한다.

## 다단 카드 스타일과 인쇄

- 공통 컴포넌트의 다단 카드 예시는 2/3/4열과 라인형·배경형·오픈형을 선택해 볼 수 있다. 기본은 **3열 라인형**이다.
- 버튼은 `aria-pressed`로 선택을 표시하며, 실제 렌더링은 `SmartECMDocuments.components.multiCards`를 호출한다. 템플릿에 별도 카드 HTML을 중복 구현하지 않는다.
- 브라우저 인쇄에서는 컨트롤 버튼을 숨기고 선택된 카드 레이아웃만 출력한다. 4열은 짧은 항목으로 제한한다.
- 화면은 중간 폭에서 4열을 2열로, 작은 화면에서 1열로 배치한다. 실제 A4 PDF에서는 선택된 열 개수를 유지한다.
- 2단 정보 블록은 `multiCards`의 `columns:2`, `style:'open'`을 재사용한다.
- 가상 사양 수치와 제안 대안은 실제 검증 결과가 아니다. 체크리스트의 빈 사각형은 완료 표시가 아니다.

## 레이아웃과 템플릿

- **세로형:** A4 210 × 297mm. 제목, 본문, 현황표, KPI, 일반 표로 기본 흐름을 확인한다.
- **가로형:** A4 297 × 210mm. 넓은 도식과 비교표를 배치한다. 인쇄 방향을 CSS named page로 지정한다.
- **표지 01:** 이전 표지 02의 **중앙 정렬형 패턴**. 우측 상단에 더 큰 SmartECM 로고(화면 기준 폭 220px)를 배치하고 제목·부제목은 페이지 중앙보다 조금 위에 위치한다. 맨 아래에는 작성자 `(주)위앤아이티 홍길동 차장`와 작성일(미리보기/인쇄 시점의 한국 날짜)을 별도 표지 메타데이터로 표시한다. 작성자 이름은 디자인 샘플용이다.
- **표지 02:** 상단 좌측 로고와 우측 문서 시리즈 라벨을 유지하되, **왼쪽 긴 세로선은 사용하지 않는다**. 제목과 부제목은 각각 **한 줄**로 작성하고 콘텐츠를 페이지 세로 중앙 부근으로 내려 배치한다. 짧은 가로 액센트 바 및 하단 발행사/문서 유형 정보는 유지한다. A4 인쇄는 한 줄을 유지하고 매우 좁은 모바일 화면에서는 잘림을 방지하기 위해 자연 줄바꿈을 허용한다.
- 두 표지는 단일 `paper()`를 사용하는 **별도 탭/별도 인쇄 문서**이다. `cover01`과 `cover02`를 각각 선택하고 인쇄하며 하나의 탭에 두 표지를 연속 출력하지 않는다. PDF에서도 미리보기의 정렬, 여백, 로고 비율을 유지한다.
- **제안서:** 개요 → 가상 고객 요구사항 → 개념 아키텍처 → 비교 대안 → 도입 흐름 → 검증·의사결정.
- **계획서:** 목적 → 범위·전제 → 일정 → 단계별 작업 → 검증 → 완료 조건·후속 조치.
- **공통 컴포넌트:** 각 요소의 실제 렌더링과 사용 규칙. 템플릿과 동일 렌더러 사용.

## 인쇄와 화면

- 인쇄 여백: 상단 20mm / 좌우 21mm / 하단 19mm.
- 기본 문서 푸터(하단 문서명·라인·페이지 번호)는 만들지 않는다. 필요시 해당 문서에서 명시적으로 설정한다.
- Chrome/Edge의 페이지 여백 상자 지원을 사용한다. 인쇄 대화상자의 브라우저 자체 머리글·바닥글은 해제한다.
- A4 본문은 고정 높이로 자르지 않는다. 자동 페이지 흐름, 반복 표 헤더, 고아 제목 방지 적용.
- Studio에서는 외부 페이지가 스크롤되고 탭·인쇄 버튼이 고정된다. iframe 내부 스크롤을 만들지 않는다.
- 작은 화면에서는 내용을 재배치한다. 화면의 반응형 규칙은 인쇄 용지 크기를 변경하지 않는다.
- 신규 요소 또는 장문 데이터를 추가한 경우 실제 PDF 전체 페이지를 렌더링하여 다시 검수한다.

## 일정2 및 라이브러리 구분 · 2026-10-28

- 공통 컴포넌트 예시 사이의 장식 구분선은 사용하지 않고 여백으로 구분한다. 표·KPI·인용문 등 각 요소 자체의 선은 유지한다.
- `scheduleGrid`는 월 그룹과 주차를 2단 헤더로 표시하고 작업 기간을 채운 셀로 표현하는 일정2 패턴이다.
- 입력: `caption`, `months: [{label, weeks}]`, `groups: [{label, tasks: [{name, start, duration, label}]}]`. start는 전체 주차의 0 기반 시작 위치, duration은 주차 수다. 범위를 벗어난 작업 구간은 거부한다.
- 실제 일정과 구분되는 샘플 표시를 넣는다. 작업 이름과 막대 안의 텍스트로 의미를 전달하고 색만으로 상태를 구분하지 않는다. 인쇄 시 배경색을 유지하고 전체 표를 가능한 한 같은 페이지에 배치한다.

## 2026-10-28 · 일정2 미니멀 스타일

- 일정2의 별도 캡션과 작업 그룹 제목 행을 제거하고 작업 6행을 예시로 제공한다.
- 흰 바탕, 가는 가로선과 최소 세로선, 연한 액센트 색의 기간 막대와 얇은 강조선을 사용한다. 고정 회색 헤더 및 고정 파랑색을 사용하지 않는다.
- Studio에서 선택한 액센트를 문서 프레임에도 동기화한다. 용지 배경과 본문 색은 기존 인쇄 기준을 유지한다.

## 2026-10-28 · 일정2 격자와 막대 정돈

- 주차 격자는 모든 작업 행에 동일한 간격으로 연속 표시한다. 기간 막대로 셀을 병합해 격자를 끊지 않는다.
- 기간 막대는 행 안쪽에 여백을 두고 5px 모서리와 연한 액센트 채움으로 표시한다. 기존 하단 강조선은 제거한다.
- 작업명과 기간의 접근성 레이블을 유지하고 인쇄에도 격자와 기간 막대를 보존한다.
